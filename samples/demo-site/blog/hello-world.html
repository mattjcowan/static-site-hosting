Hello, world

14 July 2026

This file lives on disk as /blog/hello-world.html, but you almost certainly arrived here by clicking a link to /blog/hello-world.

That is the whole trick: when a path has no extension, the host tries the .html sibling before it tries anything else. You write clean URLs in your markup and never think about it again.

Check the banner pinned to the bottom of this page — it shows what you asked for and what you actually got.

What happens if you get it wrong

Ask for /blog/hello-wrold and there is no file to match. Rather than a bare 404, the request walks up the tree looking for an index.html — and finds /blog/index.html one level up.
