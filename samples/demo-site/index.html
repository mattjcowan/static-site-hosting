This page was served from a zip file. Everything you see — the stylesheet, the script, the blog section — came out of one archive and landed on disk as an immutable release.

Try the resolution rules

Click through these and watch the banner at the bottom of each page.

  • /blog/ → the directory index
  • /blog/hello-world → finds hello-world.html
  • /blog/hello-world.html → the same file, named directly
  • /blog/does-not-exist → falls back to /blog/index.html
  • /nowhere/at/all → walks all the way up to this page
  • /missing.png → an asset, so 404.html with a 404 status
